# Qamar Kaif - First HTML Website Project

## Project Overview

This was my first static website project created during my DevOps learning journey.

In this project, I created a personal portfolio website using HTML, CSS, and JavaScript.

The website contains:
- My introduction
- DevOps Engineer profile
- DevOps tools section
- Skills section
- Projects information
- Contact details


## Website Creation Process

1. First, I created the website structure using HTML.

2. Added styling using CSS to make the website attractive and responsive.

3. Added basic JavaScript functionality for user interaction.

4. Tested the website locally to check that everything was working correctly.


## GitHub Upload Process

After creating the website:

1. Created a new repository on GitHub.

2. Added my website files into the repository:
   - index.html
   - CSS code
   - JavaScript code
   - Profile image

3. Committed the changes and uploaded the project to GitHub.


## Website Deployment

After uploading the code to GitHub, I used GitHub Pages to deploy my website.

GitHub Pages converted my HTML project into a live public website.
